# GODISALIVE — 하나님은 살아계신다

성경의 실존 근거를 **고고학 · 역사 · 과학**으로 파헤치고, 10년에 걸쳐 성경 전반의 지식 체계를 쌓아
**책 출간(2년 내)** 과 **성경 지식 LLM(10년 내)** 으로 발전시키는 프로젝트.

## 신앙 고백 (프로젝트의 기초)

> 예수님은 우리 모든 사람의 죄를 대신하여 십자가에서 돌아가셨고,
> 그 사실을 믿고 주님을 우리 삶의 주인으로 모시면 이 세상이 아닌 천국의 소망을 가진다.
> 죽고 난 다음 우리는 본향에서 하나님과 함께 다시 영원히 살아가는 부활 신앙을 믿는다.
> — 이 복음이 이 프로젝트의 기초입니다.
