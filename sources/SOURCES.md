# 소스 카탈로그 — 어디서 무엇을 찾는가

성경의 실존 근거(고고학 · 역사 · 과학)와 본문(원문 · 사본 · 번역)을 확보하기 위한 전 세계 소스 목록.
**갱신 원칙**: 새 소스를 발견하면 여기 등록하고, 접근을 실제로 확인한 날짜를 기록한다.

최종 갱신: 2026-08-22 (v1 — 접근 검증 전, Phase 1에서 전 항목 1회전 검증 예정)
