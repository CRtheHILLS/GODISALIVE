## 표준 구성 (2026-08-22 확정 — CR 피드백 반영)

1. **성경 본문** (개역한글 전문 + 필요시 히브리어/그리스어)
2. **📌 한눈에 보는 내용** ← 본문 바로 아래, 항상 먼저! 쉬운 한국어 3~5문장으로
   "이 본문이 무슨 이야기인지" 큰 그림을 그려준다. 분석은 그 다음.
3. 구조 분석 (단락 흐름, 문학 장치)
4. 원어의 보석들 (히브리어/그리스어 단어 연구)
5. 역사·고고학 배경 (현장 사진 포함 — 증거 등급 표기)
6. 신약 연결 / 해석의 역사
7. 베드로의 창 (목격자의 회고 — 감성적 적용)
8. 오늘의 결론 + 출처 + 등급 범례

## 디자인 규칙

- 쉬운 한국어, 큰 활자(17px+), 본문 인용은 명조(Batang) + 배경 강조 블록
- 표·타임라인·카드로 시각화, 시스템 폰트만 사용 (오프라인에서도 동일하게 보임)
- 모든 사실 서술에 출처, 논쟁 사안은 정직 노트(⚖)로 등급 표기
