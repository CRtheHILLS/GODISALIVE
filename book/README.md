## 주제 후보 (초안 — CR과 논의용)

1. **『돌들이 소리 지른다』(가제)** — 유물 연작 구조. 장마다 유물 1점이 주인공:
   텔단 석비 → 다윗은 있었다 / 실로암 비문 → 히스기야의 터널 공사 실화 / 빌라도 석비 → 재판정의 그 사람...
   장 구성: 발견의 드라마 → 유물이 말하는 것 → 성경 본문 → 그래서 무엇이 달라지는가.
2. **『목격자들』(가제)** — 인물 중심. 성경 외 사료로 실존이 확인된 인물들의 이야기
   (히스기야, 산헤립, 느부갓네살, 키루스, 빌라도, 가야바, 예수의 형제 야고보...).
3. **『부활 앞의 증거들』(가제)** — 예수의 역사성 집중. 비기독교 사료 → 사본학 → 초대교회 폭발적 성장 →
   목격자들의 순교. 복음 제시로 수렴하는 구조 (프로젝트 사명과 가장 직결).

## 원고 규율

- 모든 사실 서술은 `evidence/` 노트 id를 각주로 단다 (탈고 시 일반 각주로 변환).
- C등급 증거는 본문에 쓰지 않거나 "논쟁 중"임을 명시. D등급 인용 절대 금지.
- 이미지는 `assets/catalog.json`에서 license가 PD/CC0인 것만 본문 배치 (비상업 CC는 대체 이미지 찾기).
- 원고 파일: `book/manuscript/ch01-*.md` → 출력 스킬로 Word 변환하여 바탕화면 출력.
