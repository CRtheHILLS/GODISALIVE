# study/ — 공부 모드 (설교·강의 영상 → 이해 → 뉴런 연결)

> CR 지시 (2026-10-25): "유튜브 설교나 각종 기독교 지식에 관한 다양한 언어의 링크를 넣으면 CR이 쉽게 이해할 수
> 있게 다시 내어 주고, 그 지식은 10년 이상을 바라보고 뉴런처럼 점과 점으로 연결되어 지혜가 되게 하라.
> 메인 프로젝트와 별도로 존재하는 수동(수기) 모드다."

## 한 줄 설계
**링크 1개 → 자막 수집 → Peter가 소화 → ① CR용 HTML 보고서 ② 시스템용 지식 노트(설교 노트 + 새 개념 노트) ③ 지식 그래프 갱신.**
설교 한 편이 들어올 때마다 그래프에 점(개념·인물·구절·증거)이 늘고 선이 이어진다. 그래프가 자라는 것이 '지혜가 쌓이는 것'의 측정치다.

## 발동 (수동)
CR이 유튜브 링크를 붙이거나 "공부 모드", "이 설교 정리해줘", "이 강의 공부하자"라고 말할 때.
언어는 상관없다 — 한국어·영어·독일어·히브리어 강의 모두 원어 자막을 받아 Peter가 한국어로 소화한다.
절차 상세: `.claude/skills/godisalive-study/SKILL.md`

## 파이프라인
```
python study/tools/fetch.py <URL>          ① 메타 + 원어 자막 → study/sources/<id>/  (+ catalog.json)
Peter가 transcript 전체를 읽는다           ② 소화 — 쉬운 한국어, 큰 그림 먼저, 주장은 등급제로 검증
knowledge/lectures/<날짜>-<슬러그>.md        ③ 설교 노트 (frontmatter: speaker·verses·evidence·tags·report)
knowledge/{words,themes,people,places,books}/ ④ 설교가 소개한 새 개념마다 노드 노트 신설 (출처 필수, [[링크]])
evidence/<축>/                               ⑤ 역사 주장이 나오면 증거 노트 (등급 A/B/C/D)
reports/YYYY-MM-DD-공부-<주제>.html           ⑥ CR용 완성 보고서 (단일 파일) → 바탕화면 + Railway /srv/reports/
python study/tools/graph.py --open          ⑦ 지식 그래프 재생성 — 끊어진 링크·고아 노트 점검, 지도 열기
NEXT.md 갱신 → git 커밋(+push)              ⑧ 세션 종료
```

## 보고서 표준 구성 (설교·강의용 — reports/README.md의 봉독 표준을 변형)
1. 영상 카드 (제목·채널·길이·링크·자막 종류·저작권 안내)
2. **성경 본문** (설교 본문 개역한글 전문 + 핵심 구절 원어)
3. **📌 한눈에 보는 내용** — 쉬운 한국어 4~6문장, 반드시 본문 바로 아래
4. 설교의 흐름 — 타임스탬프 타임라인 (클릭하면 영상 그 자리)
5. 핵심 메시지 (설교자의 논리 사슬, 카드 3~7개)
6. 설교자가 든 그림·예화
7. 원어의 보석
8. **⚖ 검증 노트** — 설교자의 역사·배경·인용 주장을 사료로 확인, 등급 표기. 신앙 메시지는 검증 대상이 아님. (GODISALIVE 고유 가치)
9. **🧠 연결** — 기존 노트·증거·구절과 어떻게 이어졌는지 (미니 지도 + 목록)
10. 베드로의 창 — 목격자의 회고 (감성적 적용)
11. 오늘의 한 문장 + 한 주간 질문 + 출처 + 등급 범례

## 그래프 (뉴런) 규칙
- **점**: 지식 노트(kn-*) · 증거(ev-*) · 성경 장("약 2") · 설교자 · 태그 · 끊어진 링크(아직 없는 노트)
- **선**: `[[위키링크]]` · frontmatter `evidence:` · 같은 성경 장 · 같은 설교자 · 같은 태그
- 새 개념은 **노트로 만들어 점이 되게** 한다. 설교 노트 안에 묻어두면 선이 생기지 않는다.
- `[[아직-없는-노트]]`는 오류가 아니라 **할 일 목록**이다 — 지도에 빨간 점선으로 뜬다.
- `graph.py --check`는 끊어진 링크가 있으면 종료코드 1 — 세션 종료 전 한 번 돈다.
- 산출물 `knowledge/graph/graph.json`(기계용 — Phase 5 RAG·지식그래프의 씨앗) · `map.html`(사람용, 외부 의존성 없음)

## 저작권 원칙
- 설교·강의 자막 **원문은 git에 넣지 않는다** (공개 저장소). 로컬 `study/sources/<id>/transcript.*`(gitignore) + Railway Volume `/srv/study/<id>/`에 영구 보관.
- git에는 `meta.json`과 `catalog.json`(영상 정보), 그리고 Peter의 **소화 노트**(인용은 짧게)만 들어간다.
- 보고서는 설교 전문을 옮기지 않고 요약·인용 범위 안에서 작성. 원 저작권자(채널)를 명시.

## 도구
| 파일 | 역할 |
|---|---|
| `tools/fetch.py` | URL → meta.json + transcript (yt-dlp 자막: 수동 우선 → 원어 자동자막 → 없으면 Whisper 필요 보고) |
| `tools/graph.py` | 노트 스캔 → graph.json + map.html, 끊어진 링크·고아·허브 보고 (`--check`, `--open`) |
| `tools/graph_html.py` | 지도 렌더러 (캔버스 힘-배치 직접 구현, 라이브러리 없음) |
| `tools/common.py` | 영상 ID · VTT 정제(굴러가는 중복 제거) · frontmatter · 위키링크 · 구절 정규화(bible/lookup.py 책 이름표 재사용) |
| `tools/selftest.py` | 자가 테스트 — 수정 후 `python study/tools/selftest.py` 전부 통과가 증거 |

## 아직 없는 것 (필요해지면)
- Whisper 음성 인식 (자막 없는 영상) — 오디오 다운로드가 크므로 CR 승인 후 설치·실행
- 플레이리스트/채널 일괄 수집 — 지금은 영상 단위 (fetch.py에 URL 여러 개는 가능)
