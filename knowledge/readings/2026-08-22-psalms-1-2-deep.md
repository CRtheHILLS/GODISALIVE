# 시편 1·2편 심층 (2026-08-22)

**완성 보고서(HTML, 영구보관 3중)**: `reports/2026-08-22-시편-1-2편-심층.html`

## 핵심 발견 요약
1. **1-2편 = 의도적 쌍 (이중 서문)**: 아쉬레 액자(1:1↔2:12), 같은 동사 하가(1:2 묵상↔2:1 경영),
   "길 망함"(1:6↔2:12), 둘 다 무표제. 외부 증거: 탈무드 베라코트 9b-10a 단일 단락 전승,
   행 13:33 서방 사본 "첫째 시편" 독법, **4Q174가 삼하 7 + 시 1:1 + 시 2:1을 묶어 메시아 주석** (A급 실물).
2. **1편 원어**: 아쉬레(복수 감탄 "복들!"), 하가(웅얼거림 — 사 31:4 사자), 샤툴(옮겨 심긴),
   팔게이 마임(관개 수로들 — 렘 17:5-8 병행), 겨=타작마당 저녁 키질 (마 3:12 연결).
   1:1 동사 점층: 걷다→서다→앉다 (죄의 정착 3단계).
3. **2편**: 4막 드라마(열방→하늘→왕→권고). 원 맥락 = 다윗 왕조 대관식(B), 칙령의 원본 = 삼하 7:14.
   마쉬아흐→크리스토스→그리스도. 12절 "바르"(아람어) 논쟁은 정직 노트로 처리 (LXX 이독).
   해석 사슬: 쿰란(4Q174) → 세례·변화산(막 1:11, 마 17:5) → 행 4(박해 기도, 다윗 귀속 증언) →
   행 13:33(부활 적용) → 히 1:5; 5:5 → 계 12:5; 19:15.
4. **베드로 연결(페르소나 핵심)**: 벧후 1:17-18 — 베드로는 변화산에서 시 2:7 계열의 하늘 음성을
   직접 들은 귀증인. 행 4장 박해 후 공동 기도에서 시 2를 함께 불렀음.
