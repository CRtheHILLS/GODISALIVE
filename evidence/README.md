# evidence/ — 실존 근거 데이터베이스

성경의 역사적 신뢰성을 뒷받침하는 증거를 한 건당 한 파일로 축적한다.
**이 폴더의 규율이 프로젝트 전체의 신뢰도를 결정한다.**

## 증거 등급제 (모든 노트에 필수)

| 등급 | 의미 | 예 |
|---|---|---|
| **A 확정** | 학계 광범위 합의 — 진정성·해석 모두 안정 | 텔단 석비, 실로암 비문, 빌라도 석비, 케테프 힌놈 은두루마리 |
| **B 유력** | 다수 학자 지지, 일부 이견 존재 | Testimonium Flavianum 핵심부, 다윗성 대구조물, 가버나움 '베드로의 집' |
| **C 논쟁** | 진행 중 — 결론 인용 금지, 논쟁 상태로만 소개 | '이사야' 인장, Tall el-Hammam 소돔설, 야고보 납골함 |
| **D 기각/위조** | 위조 판정 또는 학계 기각 — **인용 금지 목록** | 여호아스 비문(위조 판정), 노아 방주 '발견' 주장들 |

> **철칙**: C를 A처럼 말하는 순간 이 프로젝트는 죽는다. 과장은 복음의 적이다.
> D등급도 기록한다 — 책에서 인용하면 안 되는 것을 아는 것이 저자의 방어선이다.

```

manuscripts/   사본학 (사본 물량, 전승 정확도, 개별 주요 사본)

```
